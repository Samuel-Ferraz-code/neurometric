# Capturas geradas durante o desenvolvimento

- `comparacao-*.png`: à esquerda, a imagem de referência do Stitch; à direita, a página convertida para CSS externo,
  na mesma escala (1280 px de largura, zoom 1,25).
- `previa-*.png`: telas funcionando com o banco **fictício** de testes.

Essas capturas foram feitas em um ambiente sem acesso ao Google Fonts: os ícones Material Symbols aparecem
como retângulos cinza ou como texto. No seu computador, com internet, os ícones aparecem normalmente.
Para o relatório (Apêndice C), faça capturas reais no seu navegador.
